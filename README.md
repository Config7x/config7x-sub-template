# قالب صفحه اشتراک Config7x برای پنل 3x-ui

قالب آمادهٔ صفحهٔ اشتراک (ساب) برای پنل **3x-ui** — همان قالبی که روی ساب آمازون Config7x نصب است. یک فایل `index.html` تکی و مستقل است؛ نیازی به فایل دیگری ندارد.

## نصب سریع (یک دستور)

روی سرور (با sudo) این دستور را بزنید — اسکریپت خودش قالب را دانلود می‌کند، روی پنل نصب می‌کند و منوی تنظیم را نشان می‌دهد:

```bash
curl -fsSL https://raw.githubusercontent.com/Config7x/config7x-sub-template/main/install.sh -o /tmp/install-config7x.sh && sudo bash /tmp/install-config7x.sh
```

بعد از نصب، از منوی اسکریپت می‌توانید برند، لینک‌ها، خدمات، قیمت‌ها و رنگ حباب را تنظیم کنید (قبل از هر تغییر پشتیبان گرفته می‌شود).

## این قالب چه چیزی دارد؟

- **داشبورد اشتراک** با حباب مصرف (درصد مصرف به‌صورت دایره‌ای با موج متحرک)، حجم کل / مصرف‌شده / باقی‌مانده، روزهای باقی‌مانده و تاریخ انقضا
- **اتصال سریع** — باز کردن شیت انتخاب برنامه (v2rayNG، Streisand، NekoBox، Hiddify، FoXray، Clash) با دیپ‌لینک مستقیم؛ دکمهٔ «اشتراک‌گذاری با برنامه دیگر» هم دارد
- **کپی لینک اشتراک** و **نمایش QR** اشتراک
- **لیست کانفیگ‌ها** با دکمهٔ کپی و QR برای هر کانفیگ
- **تب خرید سرویس** — جدول قیمت‌ها با دکمهٔ خرید (به فروشگاه تلگرام وصل می‌شود)
- **تب خدمات** — معرفی سرویس‌ها و ربات‌های شما (فروشگاه، بات‌ساز، ربات پیام‌ساز، …)
- **تب پشتیبانی** — کارت‌های کانال، پشتیبانی، گروه و فروشگاه
- **نمودار مصرف ۷ روز اخیر**
- تم تیره و روشن (خودکار با سیستم گوشی)، راست‌چین و فارسی، فونت وزیرمتن
- **مهم:** این قالب فقط وقتی در مرورگر باز شود داشبورد را نشان می‌دهد. برنامه‌های VPN (مثل v2rayNG) همان لیست خام کانفیگ‌ها را می‌گیرند و قالب هیچ اختلالی در ساب ایجاد نمی‌کند.

## نصب

### پیش‌نیاز
- پنل **3x-ui** (نسخهٔ MHSanaei) روی سرور
- دسترسی SSH به سرور (کاربر با sudo)

### روش اول — اسکریپت نصب و تنظیم (پیشنهاد می‌شود)

فایل `install-config7x-template.sh` را روی سرور بفرستید و اجرا کنید:

```bash
sudo bash install-config7x-template.sh
```

اسکریپت یک منوی تعاملی نشان می‌دهد:

```
 1) نصب قالب روی پنل
 2) تنظیم نام برند
 3) تنظیم لینک کانال تلگرام
 4) تنظیم لینک پشتیبانی
 5) تنظیم لینک گروه
 6) تنظیم لینک فروشگاه / ربات فروش
 7) تنظیم خدمات (تب خدمات)
 8) تنظیم محصولات و قیمت‌ها (تب خرید)
 9) تنظیم رنگ حباب مصرف
10) نمایش تنظیمات فعلی
 0) خروج
```

- **گزینهٔ ۱** قالب را نصب می‌کند: فایل را در مسیر درست می‌گذارد، پنل را روی حالت Custom می‌گذارد و x-ui را ری‌استارت می‌کند.
- **گزینه‌های ۲ تا ۹** بخش‌های مختلف قالب را تنظیم می‌کنند (برند، لینک‌ها، خدمات با افزودن/ویرایش/حذف، قیمت‌ها با افزودن/ویرایش/حذف، رنگ حباب).
- قبل از هر تغییر، از فایل قالب پشتیبان گرفته می‌شود (`index.html.bak-...`).

### روش دوم — نصب دستی

#### مرحله ۱ — گذاشتن فایل روی سرور

یک پوشه برای قالب بسازید و فایل را آنجا بگذارید:

```bash
sudo mkdir -p /opt/3x-ui-subscription-dashboard/current/theme
```

فایل `config7x-sub-template.html` را با SCP روی سرور بفرستید (مثلاً به `/tmp/`) و بعد:

```bash
sudo cp /tmp/config7x-sub-template.html /opt/3x-ui-subscription-dashboard/current/theme/index.html
sudo chmod 640 /opt/3x-ui-subscription-dashboard/current/theme/index.html
```

> نام فایل باید دقیقاً `index.html` باشد.

#### مرحله ۲ — معرفی قالب به پنل

**روش اول — از پنل (پیشنهاد می‌شود):**
پنل 3x-ui ← تنظیمات (Settings) ← اشتراک (Subscription):
- **Profile Mode** را روی **Custom** بگذارید.
- **Theme Directory** را روی مسیر پوشهٔ قالب بگذارید:
  `/opt/3x-ui-subscription-dashboard/current/theme/`
- ذخیره کنید.

**روش دوم — مستقیم در دیتابیس (اگر در پنل پیدا نکردید):**

```bash
sudo python3 -c "
import sqlite3
db = sqlite3.connect('/etc/x-ui/x-ui.db')
cur = db.cursor()
cur.execute(\"UPDATE settings SET value='custom' WHERE key='subProfileMode'\")
cur.execute(\"UPDATE settings SET value='/opt/3x-ui-subscription-dashboard/current/theme/' WHERE key='subThemeDir'\")
db.commit()
"
sudo systemctl restart x-ui
```

#### مرحله ۳ — تست

لینک ساب یک کاربر را در مرورگر گوشی باز کنید. باید داشبورد را ببینید. اگر همان لیست خام کانفیگ‌ها را دیدید، یعنی قالب هنوز فعال نشده (مسیر پوشه یا Profile Mode را دوباره چک کنید).

> تغییر فایل `index.html` بدون ری‌استارت اعمال می‌شود — کافی است صفحه را در مرورگر رفرش کنید (اگر نسخهٔ قدیمی دیدید، هارد رفرش کنید).

## امضای سازنده

پایین صفحهٔ ساب (زیر دکمه‌های ناوبری) یک خط کوچک هست: «ساخته‌شده با ♥ توسط Config7x» که به کانال سازنده لینک می‌دهد. **این امضا همیشه مال Config7x می‌ماند** — حتی اگر با اسکریپت برند و کانال خودتان را تنظیم کنید، امضا عوض نمی‌شود. بقیهٔ جاهای قالب (برند، لینک‌ها، خدمات، قیمت‌ها) با برند شما تنظیم می‌شوند. بالای فایل هم یک کامنت هست که سازنده را معرفی می‌کند (در صفحهٔ سرو‌شده دیده نمی‌شود، فقط در خود فایل).

## تنظیم و شخصی‌سازی

همهٔ تنظیمات داخل خود فایل `index.html` است. با یک ویرایشگر متن (VS Code یا Notepad++) فایل را باز کنید و موارد زیر را عوض کنید. برای هر مورد، عبارت دقیق جست‌وجو داده شده است.

### ۱. نام برند

نام برند در چند جا آمده است. مهم‌ترین‌ها:

| کجا | چه چیزی را جست‌وجو کنید | چه چیزی بگذارید |
|---|---|---|
| عنوان هدر و هیرو | `subscriptionHub: "Config7x"` (دو جا: خط fa و خط en) | نام برند خودتان، مثلاً `"MyBrand"` |
| عنوان بزرگ وسط کارت | `<div class="pz-brand-title">CONFIG 7X</div>` | نام برند با حروف بزرگ، مثلاً `MY BRAND` |
| دکمهٔ کانال در هدر | `Config7x` کنار `channel-pill` | نام کانال خودتان |

> نکته: عدد ۷ در `CONFIG 7X` لاتین است؛ اگر نام برند شما عدد دارد، آن را لاتین بنویسید.

### ۲. لینک‌ها (کانال، پشتیبانی، گروه، فروشگاه)

همهٔ لینک‌های تلگرام را با آیدی‌های خودتان عوض کنید (جست‌وجوی `t.me/` همه را نشان می‌دهد):

| لینک فعلی | کجاست | به چه چیزی عوض شود |
|---|---|---|
| `https://t.me/CONFIG7X` | دکمهٔ کانال در هدر + کارت کانال در تب پشتیبانی | کانال شما |
| `https://t.me/Mld7z` | کارت پشتیبانی | آیدی پشتیبانی شما |
| `https://t.me/Config7x_Gap` | کارت گروه | گروه شما |
| `https://t.me/DIGI7X_APP` | کارت فروشگاه + دکمهٔ خرید در تب قیمت‌ها | فروشگاه/ربات فروش شما |

متن کنار هر کارت هم قابل تغییر است؛ مثلاً:
```html
<a class="pz-support-card" href="https://t.me/CONFIG7X" ...><b>کانال Config7x</b><i>@CONFIG7X — کانفیگ رایگان و اخبار سرویس</i></a>
```
نام و توضیح را با برند خودتان عوض کنید.

### ۳. بخش خدمات (تب «خدمات»)

سرویس‌ها یک آرایهٔ جاوااسکریپت‌اند. عبارت `svc-shop` را جست‌وجو کنید؛ چهار سرویس پشت سر هم‌اند:

```js
{ cls: "svc-shop", icon: "🛒", name: "فروشگاه Config7x", id: "@DIGI7X_APP", desc: "خرید کانفیگ، اپل‌آیدی، اشتراک‌ها، هوش مصنوعی و گیفت تلگرام.", url: "https://t.me/DIGI7X_APP", btn: "ورود به فروشگاه" },
{ cls: "svc-botsazan", icon: "🤖", name: "بات‌سازان استودیو", id: "botsazan.config7x.site", desc: "با یک کلیک ربات تلگرام خودت رو بساز — بدون کدنویسی.", url: "https://botsazan.config7x.site", btn: "ساخت ربات" },
{ cls: "svc-rich", icon: "✉️", name: "تلریچ | Rich7x", id: "@Rich7xapp", desc: "ساخت پیام‌های حرفه‌ای و شیک برای کانال و گروه.", url: "https://t.me/Rich7xapp", btn: "باز کردن ربات" },
{ cls: "svc-ssh", icon: "🖥️", name: "SSH Admin Bot", id: "@sshtobot", desc: "مدیریت سرور از داخل تلگرام — سریع و ساده.", url: "https://t.me/sshtobot", btn: "باز کردن ربات" }
```

- برای هر سرویس خودتان یک خط مثل همین اضافه کنید (یا خط‌های موجود را عوض کنید).
- `icon` ایموجی سرویس است، `name` نام، `id` آیدی/آدرس نمایشی، `desc` توضیح یک‌خطی، `url` لینک، `btn` متن دکمه.
- `cls` کلاس رنگ است؛ کلاس‌های آماده: `svc-shop` (آبی/بنفش)، `svc-botsazan` (سبز)، `svc-rich` (صورتی)، `svc-ssh` (خاکستری/آبی). اگر سرویس بیشتری اضافه کردید، یکی از همین کلاس‌ها را دوباره استفاده کنید.

### ۴. محصولات و قیمت‌ها (تب «خرید»)

قیمت‌ها هم یک آرایهٔ جاوااسکریپت‌اند. عبارت `price: 60000` را جست‌وجو کنید:

```js
{ label: "۱۰ گیگ",  volume: "10 GB",  days: 30, price: 60000 },
{ label: "۲۰ گیگ",  volume: "20 GB",  days: 30, price: 110000 },
{ label: "۳۰ گیگ",  volume: "30 GB",  days: 30, price: 150000 },
{ label: "۵۰ گیگ",  volume: "50 GB",  days: 30, price: 225000, popular: true },
{ label: "۱۰۰ گیگ", volume: "100 GB", days: 30, price: 400000 },
{ label: "۲۰۰ گیگ", volume: "200 GB", days: 30, price: 700000 },
```

- `label` نام نمایشی محصول (فارسی)، `volume` حجم، `days` مدت (روز)، `price` قیمت به تومان.
- `popular: true` یعنی «پرفروش‌ترین» — فقط روی یکی از محصول‌ها بگذارید.
- برای اضافه/حذف محصول، یک خط اضافه یا حذف کنید.
- دکمهٔ خرید هر محصول به فروشگاه تلگرام شما وصل می‌شود؛ لینک آن را در بخش ۲ عوض کنید (`t.me/DIGI7X_APP` کنار `pz-buy-btn`).

### ۵. رنگ حباب مصرف

رنگ مقدار پرشدهٔ حباب با مصرف عوض می‌شود (تابع `getUsageColor` را جست‌وجو کنید). الان گرادیان این است:

- مصرف کم: فیروزه‌ای → آبی
- مصرف متوسط: آبی → بنفش
- مصرف زیاد: بنفش → صورتی/قرمز

اگر رنگ ثابت می‌خواهید، کل تابع را با یک خط ساده عوض کنید:

```js
function getUsageColor(percent, unlimited = false) {
  return "#4f9bff";
}
```

(به‌جای `#4f9bff` کد رنگ خودتان را بگذارید.)

### ۶. برنامه‌های «اتصال سریع»

لیست برنامه‌ها در `CONNECT_APPS` است (v2rayNG، Streisand، NekoBox، Hiddify، FoXray، Clash). معمولاً نیازی به تغییر ندارد؛ اگر برنامه‌ای را نمی‌خواهید، خط آن را حذف کنید.

## نکات مهم

- **این قالب فقط ظاهر صفحهٔ ساب را عوض می‌کند.** پنل، اینباندها، کاربرها و لینک ساب دست نمی‌خورند.
- قالب برای اینکه کار کند به اینترنت نیاز دارد (فونت وزیرمتن و آیکون‌های Font Awesome از CDN می‌آیند و QR از `api.qrserver.com` ساخته می‌شود). اگر کاربر اینترنت نداشته باشد، صفحه باز می‌شود ولی فونت و آیکون‌ها ساده‌تر دیده می‌شوند.
- قبل از هر تغییر، از فایل `index.html` یک کپی پشتیبان بگیرید.
- بعد از هر ویرایش، فایل را دوباره روی سرور بگذارید و صفحه را هارد رفرش کنید (در کروم موبایل: منو ← «دسکتاپ سایت» را خاموش/روشن کنید یا کش را پاک کنید) تا نسخهٔ جدید را ببینید.
- نسخهٔ اصلی این قالب از پروژهٔ `ldwnil/sub-temp` شروع شده و برای Config7x بازطراحی و گسترش داده شده است.
